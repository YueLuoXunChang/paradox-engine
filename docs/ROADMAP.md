## 〇、目标（一句话）

paradox-engine 最终形态：**一个分情况分层、挂上 AI 就能用的逻辑建模引擎**——
经典逻辑打底（别人无门槛）、悖论/创生当发动机（独特卖点）、MT-MP-TL 当骨架、
冷门逻辑按场景选、AI 可调用；能处理复杂学科题目，也能让简单问题走轻量道；
撞到图灵机/哥德尔这类墙时，不假装能穿，而是"测墙→钻墙→看墙→换位→创生"。

## 一、最终分层架构

```
第 4 层  AI 挂载层        AI 可调用（工具/管线/协议）
第 3 层  冷门逻辑层       次协调 / Dung / 非单调 …（按痛点选）
第 2 层  悖论/创生层      悖论测度·注解·递归修正 · 对位创生（独创主场）
第 1 层  经典逻辑层       命题 → 谓词 → 时序 → 模态（地基，经典共识）
第 0 层  MT-MP-TL 骨架     点 / 线程 / 拓扑 / 操作（自有骨架）
```

### 阶段 1 · 第 1 层经典逻辑学基础（✅ 已完成 2026-09-06）
目标：把**经典逻辑学的基础全貌**做出来——不是几个判定器，而是按数学
逻辑标准四分法（语义判定 / 证明论 / 可计算性 / 类型与模型）覆盖地基。
这是建模的底子，也是给外人展示"这不是玄学"的证据。
> 每构件完整规格（管什么/算法/输入输出/验收/边界）见
> 任务指标《39_逻辑建模引擎_经典逻辑层详规》v2（808 行，9 构件族）。

**全景对照（为什么这些才算"基础"）**：

## 四、执行纪律（每阶段必守）

1. 每构件：机制形态（run→dict + PORTS + 自测）+ 中文注释 + 诚实拦截；
2. 每阶段：全量测试通过 + 回测记录记账；
3. 外部借鉴：标注来源 + 归"借鉴"区（不混原创区，落落三问纪律）；
4. 诚实边界：不宣称推翻图灵/哥德尔；不可判定=可诊断态非死胡同；
5. 中文友好：所有解释/输出中文；不加版本号。

## 五、风险与边界（诚实声明）

- 经典逻辑实现是"标准件"：网上有大量参考实现——我们的增量在
  **组合方式（撞墙管线/共振带收敛/对位创生）**，不在重造命题逻辑；
- 一阶逻辑半可判定：undetermined 是合法输出，不许硬截断；
- 对外展示：第 1 层证明"靠谱"（经典共识），第 2 层证明"独特"（落落独创）。
