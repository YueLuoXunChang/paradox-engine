# 公式卡：一元谓词判定（monadic_fol）

> 概念来源：经典共识（Löwenheim 1915 / 表列法经典结果）——**只留一元谓词**，
> 一阶逻辑立刻从半可判定变成可判定；这是"可判定片段"的教科书入口。
> 代码：engine/classical/monadic_fol.py · 测试：engine/classical/test_monadic_fol.py
> 本构件归第 1 层（经典地基层）：借的是判定性结论，不掺私货。

## 一、导言

一阶逻辑一般是半可判定的（有效式能枚举，无效给不出）。但把谓词限制成
**只作用在一个变量上**（P(x)、Q(x)…，不出现 P(x,y)），判定性就回来了：
经典结论说，k 个一元谓词的公式若可满足，则在规模 ≤ 2ᵏ 的域上就可满足——
于是"枚举小域上所有谓词外延"这件事，本身就是完备判定。

## 二、判定原理

谓词外延穷举 + 有限域展开：
- 域取规模 n，逐一枚举每个谓词的外延（域的任意子集），得到一次完整的
  "谓词解释"；
- 在这一解释下按经典二值语义求值（∀x 遍历域上所有元素）；
- **判有效**＝判"公式的否定不可满足"：在 1..2ᵏ 的全部域上穷举，
  找不到反模型就是有效式；找到就是无效，并把反模型交出来。

## 三、性质（P）

- P1 经典有效式：∀x P(x) → ∃x P(x) 判 valid；量词对偶 ¬∀x P(x) ↔ ∃x ¬P(x)
  判 valid；
- P2 ∧ 可分配：∀x (P(x) ∧ Q(x)) ↔ (∀x P(x) ∧ ∀x Q(x)) 判 valid；
- P3 ∨ **不**可分配：∀x (P(x) ∨ Q(x)) → (∀x P(x) ∨ ∀x Q(x)) 判 invalid，
  反模型规模 ≥ 2（可复核：在它上面公式确实为假）；
- P4 谓词数 k ≤ 2 时是完备判定（域取到 2ᵏ = 4 就够给是/否结论）。

## 四、公式（判定结构）

```
run({formula})
  ├─ valid      ：1..2^k 的全部域上穷举，否定不可满足
  ├─ invalid    ：找到反模型（domain_size + 各谓词外延，可复核）
  ├─ undecided  ：k=3 时小域搜索没找到反模型（**搜索不完备 ≠ 有效**）
  └─ size_limit ：k>3（不假装能算）
诚实拦截：自由变量 / 二元谓词 / 函数符号 → parse_error
```

## 五、注记与边界

- **只判闭公式**：出现自由变量一律 parse_error（本构件只做闭片段）；
- 只认一元谓词（变量统一用 x）：二元以上谓词、函数符号、等词都不在这里
  （等词另有 equality_tableau 构件）；
- k = 3 时完备判定要把域枚举到 8，量太大：只做小域搜索，找不到报
  undecided——**搜索不完备不等于不可满足**，这一条不许拿来当反例用；
- 边界只写"这个片段可判"，不宣称一阶逻辑整体可判（那正是墙本身）。
