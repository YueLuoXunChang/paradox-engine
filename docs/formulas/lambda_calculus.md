# 公式卡：λ 演算构件（lambda_calculus）

> 概念来源：经典 λ 演算（Church）——非落落原创，经典共识
> 代码：engine/classical/lambda_calculus.py · 测试：engine/classical/test_lambda_calculus.py
> 与体系咬合：**Y 组合子 = 不动点 = P-Logic 自指律 X=f(X) 的计算版**

## 一、导言

λ 演算是"函数即对象"的最小计算模型——只有 λ 抽象、应用、变量三种构造，
却与图灵机同样强大（邱奇-图灵论题）。它是自指（Y 组合子）最干净的形式，
也是递归与类型论（1.9）的语义基础。

## 二、语法与归约

```
项 M ::= x | λx.M | M N
α 等价：λx.M = λy.M[y/x]（换绑变量名）
β 归约：(λx.M) N → M[N/x]（代入——计算的本质）
η 归约：λx.M x → M（x 不自由）
```

归约策略：正规序（最左最外）——保证找到范式（若存在）；应用序快但可能
不终止。引擎默认正规序。

## 三、性质（P）

- P1 邱奇论题：λ 演算 = 图灵机 = 递归函数（同一可计算函数类）；
- P2 捕获避免：替换时被替换的自由变量不被 λ 绑定捕获（α 换名）——
  (λx.λy.x) y → λy1.y 而非错捕的 λy.y；
- P3 Ω=(λx.xx)(λx.xx) 无 β 正规形（自应用不终止）；
- P4 Y f = f (Y f)：Y 组合子给出任意函数的不动点——递归 = 不动点 =
  **P-Logic 自指律 X=f(X) 的构造性实现**；
- P5 邱奇编码：自然数/真值/算术全用函数表达（succ/add/mult）。

## 四、公式（判定结构）

```
run({expr 或 mode})
  ├─ mode=beta_normal：正规序归约 → normalized/step_limit/diverged
  ├─ mode=self_apply：Ω 自应用 → step_limit（诚实不卡死）
  ├─ mode=church：邱奇数 n 应用 succ → church_number=n+1
  ├─ mode=factorial：n!（Y 递归有界展开）
  └─ 解析失败/缺输入 → 诚实拦截
```

## 五、注记与边界

- **Ω 无范式**：引擎跑步数上限报 step_limit，不假装能归一化；
- **Y 无 β 正规形**：用它定义递归用**有界展开**（算 n 步后停）——输出标注
  "有界"（工程化递归的标准做法）；
- **邱奇算术是演示**（自指/递归的教学），不是高效数值计算；
- 自指双视角：本构件（无类型自指 Y）与 1.9 STLC（类型拦住自应用）对照——
  类型能阻止 Ω，但代价是表达力下降。
