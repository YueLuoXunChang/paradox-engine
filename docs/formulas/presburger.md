# 公式卡：Presburger 算术判定（presburger）

> 概念来源：**外部经典共识**——Presburger 1929：算术里只留加法和常数乘，
> 判定性就保住了；一加变量乘变量（皮亚诺算术 PA）立刻掉进不可判。
> 归借鉴区（借判定性结论与量词消去的做法）。
> 代码：engine/classical/presburger.py · 测试：engine/classical/test_presburger.py
> 本构件归第 1 层（经典地基层）：可判定地图上那条"可判"现在真算得动。

## 一、导言

"整数上加加减减的式子，能不能判？"——能，只要没有变量乘变量。
本构件把这件事做成能跑的判定：给一条 Presburger 公式，判它在整数上
**是不是恒真**，或**有没有解**；结论另附**消去量词后的等价式**与反例/见证。

## 二、判定原理

量词消去（一个量词一个量词地消掉），看这一支给 x 下了什么界：
- **有下界时**：最小的那个解一定落在"某个下界 + 一个周期以内"——
  把这段候选值逐个代回去，代完 x 就没了；
- **没有下界时**：x 往负方向走多远都行，上界自然满足，剩下要操心的只有
  整除条件能不能**同时**成立——查一个周期内的余数够不够用即可。
消完所有量词后公式里只剩常数，求值就是结论。

## 三、性质（P）

- P1 奇偶覆盖：∀x ∃y (y+y = x ∨ y+y+1 = x) 判 **true**（每个整数非偶即奇）；
- P2 无解：∃x (2·x = 3) 判 **false**（左边永远是偶数）；
- P3 同余打架：∃x (2 | x ∧ 2 | x+1) 判 **false**——**整除条件要一起成立**
  才算数（这类"单个都可行、合起来不行"正是消元里最容易写错的地方）；
- P4 系数统一与界的开闭：∃x (2x ≥ 3 ∧ 2x ≤ 4) 判 true（x=2 在窗口里），
  而 ∃x (2x > 4 ∧ 2x < 6) 判 false（2x=5 取不到）。

## 四、公式（判定结构）

```
run({formula, mode})
  ├─ mode='validity'（默认）：整数上恒真吗？     → true / false
  ├─ mode='satisfiable'      ：整数上有解吗？     → true / false
  ├─ 附带 equivalent（消去量词后的等价式）+ counterexample / witness
诚实拦截：变量乘变量 → parse_error（那是 PA，不可判定）
规模上限：系数 / 候选周期 / 分支数 / 整次判定的代入次数 → 超了报 size_limit
```

## 五、注记与边界

- **没有乘法**：变量乘变量、变量当次数一律 `parse_error`——不是偷懒，
  是那条线一过就不可判定（见地图里的 PA 条目）；
- 只在**整数**上判：自然数版＝给每个量词变量自己加一条 `x ≥ 0`（这种写法认）；
- **规模有上限**：系数统一后的系数、候选周期、分支数、整次判定的代入次数
  都有上限，超了报 `size_limit` 并说明——**上限是诚实的，不是判定结论**；
- 最坏复杂度超指数（Fischer–Rabin 1974 的下界），只适合小式子，
  **不是快速判定器**；
- 只诊断不决策：给的是"这条式子在整数这套语义下真 / 假"。
