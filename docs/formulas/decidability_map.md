# 公式卡：可判定片段地图 · 算术层级（decidability_map）

> 概念来源：**外部经典共识**——可判定性与算术层级（Gödel 1931 不完备 /
> Church 1936·Turing 1936 不可判定 / Presburger 1929 可判定算术 /
> Kripke 1963·1965 模态可判 / Thomason 1975 一般框架不可判 /
> Löwenheim 1915 一元谓词可判 / Soare 递归论层级）。归借鉴区，逐条标源。
> 代码：engine/classical/decidability_map.py · 测试：engine/classical/test_decidability_map.py
> 本构件归第 1 层（数学底座）：**是一张可查的地图，不是判定过程**。

## 一、导言

引擎说"这个问题算不清"时，凭什么是算不清？本构件给一张**可查的墙地图**：
哪些问题学界已证可判、哪些半可判、哪些有定理兜底说不可判；算不清的又
"算不清到哪一层"（算术层级 Δ1/Σ1/Π1/Σ2/Π2），以及**引擎自己在每层承诺什么**。

## 二、判定原理

不是判定过程，是**参考文献表 + 引擎承诺**：
- **片段查询**：按逻辑系统/问题名查判定结论、算术层级、复杂度、出处，
  以及"引擎里有没有对应构件"（有就跑得动，没有就诚实说没有）；
- **层级查询**：Δ1/Σ1/Π1/Σ2/Π2 的定义、完全问题代表、引擎承诺；
- **地图总览**：整张墙按可判 / 半可判 / 不可判分组；
- **接线演示**：真跑引擎构件，把"能算的"和"算不清的"摆在一起。

## 三、性质（P）

- P1 Δ1（可判定）→ 引擎**给是/否结论**（命题逻辑、一元谓词、Presburger
  这些条目现在都能真跑）；
- P2 Σ1（递归可枚举）→ 引擎只能"**枚举到才给是**"（停机：跑出来停就是停），
  枚举不到**不给否**；
- P3 Π1 及以上 → 引擎不承诺结论，只做诚实报告（挡在门口）；
- P4 `engine_component` 为 `None` 的条目 = 引擎**没做**，诚实标的空白
  （数学底座里的 PA / 任意框架模态 / 二阶就标在这儿），
  标了构件的条目保证能 import 并真跑（有测试兜底）。

## 四、公式（判定结构）

```
run({mode, system, level})
  ├─ mode='lookup'    ：{system}     → found / unknown_system
  ├─ mode='hierarchy' ：{level}      → level_found / unknown_level
  ├─ mode='map'       ：整张墙       → mapped
  └─ mode='demo'      ：真跑构件接线 → demo（逐件 verdict）
输出：entry（片段条目）/ level（层级条目）/ fragments（地图或演示行）
```

## 五、注记与边界

- 这张表是**人工整理的参考文献表**，不是判定过程：它回答"这一类问题学界
  结论是什么"，**不替你判某个具体式子**；
- 复杂度栏只在文献有公认结论时填写，不确定就留空（不猜）；
- "可判"条目里引擎没实现的，一律标 `engine_available=False`——**不假装能算**；
- 地图上的每条结论都带出处（Church / Turing / Gödel / Presburger / Kripke /
  Thomason / Soare 等），借来的归借鉴区。
