# 公式卡：一阶谓词逻辑构件（first_order）

> 概念来源：经典逻辑（一阶谓词逻辑标准语义）——非落落原创，经典共识
> 代码：engine/classical/first_order.py · 测试：engine/classical/test_first_order.py
> 本构件归第 1 层（经典地基层）：只做经典框架内能算的，不掺私货。

## 一、导言

在命题逻辑之上加对象、谓词、量词——建模复杂学科题目的主力表达层。
"所有人会死，苏格拉底是人，所以苏格拉底会死"——量词 ∀ 把"所有"
变成可推理的对象。

## 二、判定原理（适用方法：有限论域展开）

一阶逻辑整体**半可判定**（哥德尔完备但不可判定），但**有限论域上可判定**：

```
∀x φ(x)  →  φ(o₁) ∧ φ(o₂) ∧ ... ∧ φ(oₙ)   （对论域每个对象展开）
∃x φ(x)  →  φ(o₁) ∨ φ(o₂) ∨ ... ∨ φ(oₙ)
```

展开后变成无量词命题公式 → 交给命题逻辑构件（propositional.py）判定；
反例指派再映射回"对象模型"（谓词+对象 的真假）给人看。

## 三、性质（P）

- P1 三段论有效：∀x(人(x)→会死(x)) ∧ 人(苏) ⊢ 会死(苏)；
- P2 规则实例化：∀ 规则对论域每个对象逐例成立；
- P3 传递链：∀x(P→Q) ∧ ∀x(Q→R) ⊢ ∀x(P→R)；
- P4 逻辑后承：query 是 premises 的逻辑后承 ⟺ 无模型使 premises 真而 query 假；
- P5 反例模型：not_entailed 时输出使前提真结论假的对象指派。

## 四、公式（判定结构）

```
run({universe?, facts, rules, query})
  ├─ 缺 query → query_pending
  ├─ 解析任一公式失败 → parse_error（诚实拦截，不硬算）
  ├─ 收集论域（显式 universe ∪ 公式常量）
  │    └─ 论域空且含量词 → no_universe（空论域语义特殊，诚实不判）
  ├─ 展开：facts+rules（已知真）与 query 各自在论域上无量词化
  ├─ 原子数 > 上限 → size_limit（指数风险，诚实报规模）
  └─ 复用命题引擎判 (∧premises) → query 有效性
       ├─ valid → entailed
       └─ invalid → not_entailed + 反例模型
```

## 五、注记与边界

- **自由变量/常量**：项位置的裸名默认是**论域对象（常量）**，不是变量；
  变量只由 ∀/∃ 引入（如 "∀x(人(x)→…)" 中的 x）；
- **经典语义**：只判"逻辑后承"，不含非经典算子；前提矛盾时经典爆炸律
  （ex falso）由命题层语义自然处理——本构件不做非经典处理（那是第 2/3 层）；
- **量词作用域**：语法纪律——∀x(公式) 必须带括号显式范围；
- **诚实边界**：有限论域保证可判；大论域/多规则展开可能指数爆炸——
  size_limit 诚实报告，建议缩小论域或拆分，不悄悄截断；
- 输出带 counterexample_model（对象模型），供步 5 判输出与给人看。
