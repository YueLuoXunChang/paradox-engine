# 公式卡：模态逻辑构件（modal）

> 概念来源：经典模态逻辑（Kripke 可能世界语义）——非落落原创，经典共识
> 代码：engine/classical/modal.py · 测试：engine/classical/test_modal.py
> 本构件归第 1 层（经典地基层）：表达"必然/可能"及广义模态（知识/义务/时间
> 都是模态的实例），用可能世界语义判定。

## 一、导言

命题逻辑问"P 真吗"，模态逻辑问"P 必然真吗（□P）/可能真吗（◇P）"。
语义用**可能世界**：一个世界是"事情的一种可能情况"，世界之间有可达关系
（从世界 w 能看到哪些世界），□P = 所有可达世界 P 真，◇P = 存在可达世界 P 真。

## 二、系统与可达关系假设

| 系统 | 可达关系要求 | 典型结论差异 |
|---|---|---|
| K | 无 | □p→◇p **不成立**（无自反时反例） |
| T | 自反 | □p→◇p 成立 |
| S4 | 自反+传递 | □□p ↔ □p 一类成立 |
| S5 | 等价（自反+对称+传递）| ◇□p → □p 成立 |

**白箱纪律：输出必须标注所用系统**——同一公式在不同系统结论不同，
不裸说"成立"。

## 三、判定原理

给定世界集 W + 可达关系 R + 原子真值指派，递归求值：
□φ @w = ∀v∈R(w): φ@v（无可达世界则真空真）
◇φ @w = ∃v∈R(w): φ@v
框架自检：用 T/S4/S5 时先验证 R 满足对应性质，不满足则诚实拒绝
（system_mismatch），不假装语义有效。

## 四、性质（P）

- P1 □/◇ 对偶：□φ ⟺ ¬◇¬φ（语义上成立，可用于等价改写）；
- P2 系统依赖：□p→◇p 在 K 可假、在 T 必真——结论绑系统；
- P3 框架自检：T/S4/S5 要求可达关系有对应性质，不符即拒绝；
- P4 真空真：K 下无可达世界的世界使 □φ 真（经典语义）。

## 五、公式（判定结构）

```
run({worlds, access, system, assign, formula, world})
  ├─ 缺 formula → formula_pending
  ├─ 非法 system → parse_error
  ├─ 缺 worlds / world 不在集 → world_missing
  ├─ 框架自检失败 → system_mismatch（诚实拦截）
  ├─ 解析失败 → parse_error
  └─ 求值 → true / false（boundary 标注所用系统）
```

## 六、注记与边界

- 只做经典模态（K/T/S4/S5）；认知/道义/时态是广义模态实例，后续按需扩展；
- 无限世界集只判有穷片段（本版输入即有穷）；
- assign 用"原子→为真的世界列表"表达；缺省某原子 = 全假；
- 结论永远带系统标注——换系统结论可能不同（白箱纪律核心）。
